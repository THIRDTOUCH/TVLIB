# AI短剧创作工作台 v3.0

## 🎬 新版功能

### ✨ Phase 5 新增功能

1. **云端同步系统**
   - 同账号多设备同步
   - 本地/云端双模式
   - 自动同步 + 手动同步

2. **创作素材库**
   - 角色/场景/对白/剧情素材
   - 收藏功能
   - 快速调取

3. **大数据查询**
   - 全网素材搜索
   - 智能推荐
   - 趋势分析

## 🚀 快速开始

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

## ⌨️ 新增快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+S` | 打开同步面板 |
| `Ctrl+Shift+M` | 打开素材库 |
| `Ctrl+Shift+B` | 大数据搜索 |
